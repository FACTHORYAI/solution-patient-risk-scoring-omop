# Sample data

Every file below is synthetic: an invented OMOP 5.3 extract of heart-failure patients,
generated by [`generate_sample.py`](generate_sample.py). No real patient, record or population
is used. Licence: CC0-1.0. The folder is about 350 KB, far under the 5 MB per file and 20 MB
per folder limits.

The raw tables follow the OMOP CDM 5.3 column names, reduced to the columns this
pipeline reads:

900 invented persons: 650 are diagnosed with heart failure with enough observation before and
follow-up after it, and form the target cohort; 90 are diagnosed too early in their
observation, 70 have no follow-up visit and 90 never have the diagnosis, so the jobs must leave
them out. There are 13,827 visits, 3,222 condition records, 1,925 condition eras and 1,648 drug
exposures, dated 2018 to 2025. Of the 650 cohort members, 283 have an emergency-room visit in the
risk window.

The generator builds a signal into the outcome: the probability of an emergency visit is a
logistic function of age at diagnosis, the number of comorbidities and their occurrences, prior
emergency-room visits and warfarin exposure, plus noise. Gender and race have no effect on it.
The model's test ROC AUC of about 0.78 on this sample therefore says nothing about any real
population or model.

The derived tables are written by running this repository's own jobs on the raw tables with
their default parameters, so the sample is consistent with the code.

To regenerate (the same seed always gives the same files):

```
uv run python data/generate_sample.py
```
